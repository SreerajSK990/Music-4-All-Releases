# Music 4 All releases

Official Windows and Android downloads for Music 4 All.

- [Windows 1.2.0](https://github.com/SreerajSK990/Music-4-All-Releases/releases/download/desktop-v1.2.0/Music.4.All.Setup.1.2.0.exe)
- [Android 0.3.0](https://github.com/SreerajSK990/Music-4-All-Releases/releases/download/android-v0.3.0/Music4All-0.3.0.apk)
- [All releases](https://github.com/SreerajSK990/Music-4-All-Releases/releases)

Application source is maintained in [Music-4-All](https://github.com/SreerajSK990/Music-4-All). This repository hosts release packages, release notes and separate update metadata for Windows and Android.

Updates are optional. The apps verify the signed release feed and package hashes, then wait for the user to choose installation. Android verifies the installed application's signing identity.
